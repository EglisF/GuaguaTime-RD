## 🌟 Características

- 🗺️ **Planificación de rutas** entre barrios de Santo Domingo
- 💰 **Cálculo de costos** y tiempos de viaje
- ⭐ **Sistema de favoritos** con almacenamiento local
- 🌙 **Tema claro/oscuro** automático
- 🌐 **Multidioma** (Español/Inglés)
- 📱 **Diseño responsive** para móviles
- 🔄 **Generación automática** de rutas
- 📲 **PWA** - Funciona sin conexión

## 🛠️ Instalación

```bash
# Clona el repositorio
git clone https://eglisf.github.io/GuaguaTime-RD/

# Entra al directorio
cd guaguatime-rd

# Abre en tu navegador
open index.html
O simplemente abre el archivo index.html en tu navegador.

text

🎯 Uso
Selecciona tu barrio de origen y destino

Haz clic en "Calcular rutas"

Filtra por tiempo, costo o transbordos

Guarda tus rutas favoritas

Cambia entre tema claro/oscuro e idiomas
